
# Controle de Gastos

----------

## Contexto

Crie uma **aplicação SPA** para controle de gastos.

## Requisitos

1.  O usuário seleciona um gasto do seu dispositivo.
2.  O usuário pode escolher o gasto.

## Requisitos Adicionais

1.  O sistema apresenta botões para Adicionar ou Remover um gasto.
2.  O sistema apresenta botões para avançar ou voltar um gasto.
3.  O sistema apresenta uma barra mostrando quanto falta para o gasto ser pago.

## Stack

-   Html, CSS e Js puro.
-   Utilize bibliotecas populares para reduzir código, erros e manutenção.
-   Vou hospedar no Git Pages.

## UI/UX

-   Mobile First.
-   Interfaces como se fosse um jogo de pixel art.
-   Efeitos em botões e outros componentes.

## Instroções para Agentes de IA

1.  Analise sempre a viabilidade do desenvolvimento.
2.  Não havendo viabilidade, não execute a tarefa e solicite interação humana.
3.  Todo ajuste, correção, incrementação, registre um um arquivo de Backlog. Salve o arquivo em /spec/backlog.md registrando a data, a hora e a tarefa executada.
